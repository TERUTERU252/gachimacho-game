# 育てろ！ガチマッチョくん

ガチマッチョを育成するブラウザゲームのプロトタイプです。

## 主な機能

- トレーニング
- 食事
- 休養
- 疲労・栄養・体脂肪の管理
- 成長ランク変化
- ボディメイク大会
- パンチ大会
- 早食い大会
- 称号獲得
- 育成ログ

## 起動方法

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
